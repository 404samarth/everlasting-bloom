# Everlasting Bloom

Create a premium, cinematic and emotionally memorable Indian wedding website designed primarily for mobile phones.

This should NOT look like a normal wedding invitation template. It should feel like a luxury digital experience — something guests remember after opening the link.

The website should be romantic, elegant, mysterious, interactive and premium, with beautiful animations and smooth transitions.

IMPORTANT: Do not make it childish, overly decorative, overly red/pink, or filled with random flowers and wedding clipart.

1. Overall Visual Identity

Create a sophisticated Indian wedding aesthetic.

Use a premium romantic colour palette such as:

Deep wine / burgundy

Warm ivory / cream

Soft blush pink

Very subtle muted gold

Premium black for the suspense opening

The colours should feel like love, celebration and luxury.

Use:

Elegant serif typography for names and major headings

Clean modern typography for normal text

Cinematic photography

Soft gradients

Subtle glow

Beautiful light/shadow effects

Smooth image reveals

Slow but not boring animations

Premium transitions between screens

The design should feel closer to a luxury fashion/editorial website and cinematic wedding film than a conventional wedding website.

2. MOBILE-FIRST FULLSCREEN EXPERIENCE

The website is primarily designed for mobile phones.

Make every major screen use the maximum available mobile viewport.

Use modern viewport sizing such as 100svh where appropriate.

The experience should feel like a full-screen mobile experience with:

No unnecessary margins

No wasted vertical space

Large visual elements

Touch-friendly buttons

Smooth transitions

Proper support for different phone screen sizes

Important: use the browser's available viewport as fully as possible. Do not create an artificial app-install requirement.

The website should also remain responsive on tablets and desktops.

3. SPECIAL OPENING EXPERIENCE

This is the MOST IMPORTANT part of the website.

When someone opens the link, they should NOT immediately understand that it is a wedding website.

Create a cinematic suspense sequence before the main website.

Scene 1 — Premium Black Opening

For approximately 2–3 seconds, show a very dark premium black screen.

It must NOT look like a plain empty black screen.

Use:

Very subtle black gradients

Soft moving light

Very faint texture

Cinematic shadows

Extremely subtle particles/glow

In the centre, slowly show:

"Wait..."

The typography should be elegant and minimal.

Scene 2 — Ganesh Ji

Then smoothly transition to a beautiful, premium artistic image/illustration of Ganesh Ji.

Display it for approximately 3 seconds.

The visual should feel:

Elegant

Spiritual

Premium

Cinematic

Do not use a cheap-looking cartoon or generic clipart style.

Use a sophisticated visual treatment with subtle light and motion.

Scene 3 — Suspense Message

Gradually transition from the Ganesh Ji scene.

Show a short mysterious line such as:

"Bas thoda sa wait..."

Then something more intriguing such as:

"Kyuki jo aage hai... woh aap soch bhi nahi rahe."

Keep the wording short.

The visitor should feel:
"Wait... what is this?"

Do NOT use messages about scams, hacking, phones being hacked, etc.

The suspense should feel premium and playful, not frightening.

Scene 4 — Blurred Couple

Now introduce a photograph of the bride and groom.

The photograph should initially be heavily blurred so that the visitors cannot identify the couple.

Place a subtle line:

"Before we begin..."

The couple photograph remains blurred.

Then ask:

"Ek chhoti si choice..."

Show:

English | हिंदी

The user chooses their language.

Scene 5 — Photo Reveal

After language selection, gradually reduce the blur.

The photograph should become approximately 30% visible/recognizable, but NOT completely clear.

Do this with a beautiful cinematic transition.

The user should still wonder:

"Kaun hai?"

Scene 6 — The Date Mystery

Now show a short Hinglish message.

Example:

"Aapko pata hai 18–19 November ko kya hai?"

Then provide two elegant buttons:

"Yes ❤️"

"No 👀"

The exact dates and text must be easy to change later.

If the visitor chooses "No", show a playful short response before continuing.

If they choose "Yes", continue naturally.

The experience should remain fun and premium.

Scene 7 — Relationship Selection

Now ask:

"Achha... toh aap inke liye kaun hain?"

Show these choices:

Bride Family

Groom Family

Bride Friend

Groom Friend

Bride/Groom Relative

Make the selection screen beautiful and interactive.

After selection, transition into the main wedding website.

4. LANGUAGE STYLE

This is extremely important.

Do NOT write the entire website in difficult English.

Even when the visitor selects English, use simple English mixed naturally with Hindi/Hinglish.

The audience includes Indian family members who may not be comfortable reading complicated English.

Use premium Hinglish such as:

"Some moments are meant to be celebrated together."

"Ab jab aap yahan tak aa hi gaye hain..."

"Ek nayi kahaani shuru hone wali hai."

"Your presence will make this celebration even more special."

For paragraphs, invitations and emotional sections, prefer simple Hinglish/Indian English rather than formal Western-style English.

Hindi should also be available when Hindi is selected.

Do not mechanically translate every sentence. Preserve the emotional and premium feeling of the original message.

5. MAIN HOMEPAGE

After the opening experience, create a beautiful homepage.

The homepage should contain:

Hero Section

Bride and Groom names

Wedding date

Premium couple photograph

Short emotional line

Elegant entrance animation

Example style:

"Do dil, ek kahaani... aur ab ek nayi shuruaat."

Keep actual names editable.

6. OUR STORY

Create a beautiful section introducing the couple.

Include:

How they met

Their journey

Small memories

Short introduction of both

Use a storytelling layout rather than a boring paragraph.

Keep all text editable.

7. MEET THE FAMILIES

Create a premium family introduction section.

Separate:

Bride's Family

Groom's Family

Include:

Family photograph

Names

Short introduction

Elegant animations

Make it feel like welcoming the visitor into the family.

8. WEDDING COUNTDOWN

Create a large premium countdown.

Show:

DAYS
HOURS
MINUTES
SECONDS

until the wedding.

Use beautiful animated numbers.

The countdown should be visually important but elegant.

After the wedding date passes, this section should automatically transform into a post-wedding message.

9. WEDDING FUNCTIONS

Create an elegant timeline/cards section for every function.

Each function should include:

Function name

Date

Time

Venue

Dress code

Short description

Use an elegant timeline or editorial card design.

Everything must be editable later.

10. DIGITAL WEDDING CARD

Create a premium section containing the digital wedding invitation/card.

Show a beautiful preview.

Include:

"View Invitation"

and

"Download Card"

Make the card easy to replace later.

11. SPECIAL WEDDING INVITATION / PERSONAL INVITATION

Create a VERY PREMIUM highlighted section where the family personally invites guests to attend the wedding.

This should feel different from the normal information sections.

Use a beautiful full-width background with:

Premium texture

Elegant Indian wedding visual elements

Subtle gold/light effects

Large elegant typography

Cinematic animation

The message should communicate something like:

"Shaadi sirf do logon ka milan nahi hoti...
yeh do parivaaron ka ek saath aana hota hai."

Then a heartfelt invitation in simple Hinglish:

"Is khoobsurat mauke par aapka saath humare liye bahut khaas hai.
Aap zaroor aaiyega, milkar is celebration ko aur yaadgaar banayenge."

Make this section emotionally warm, respectful and premium.

The exact message must be easy to edit.

12. BLESSINGS & TESTIMONIALS

Create a beautiful testimonial section.

Show messages from:

Family

Friends

Relatives

In-laws

Also create a "Leave Your Blessings" form.

Visitors can submit:

Name

Relation

Blessing/message

The submitted messages should eventually be stored and displayed in the testimonials section.

Design the cards beautifully.

13. SHARE YOUR MEMORY

Create a section asking:

"Do you have a photo with the bride or groom?"

Then:

"Share it with us ❤️"

Allow guests to upload photographs they have with the bride or groom.

Create a beautiful upload experience.

These memories should eventually become part of the wedding's digital memory collection.

14. WEDDING INSTAGRAM

Create a premium section introducing the couple's dedicated wedding/memory Instagram account.

Explain that this account will hold:

Wedding moments

Memories

Photos

Videos

Future memories

Add a prominent:

"Join Us on Instagram"

button.

15. AFTER-WEDDING TRANSFORMATION

This website must be designed so it does not become useless after the wedding.

After the wedding, transform the website into a permanent digital wedding photobook.

The post-wedding version should contain:

Wedding photographs

Wedding videos

Guest photographs

Blessings

Important moments

Memories

The design should remain the same but the homepage should change from invitation/countdown to:

"Our Beautiful Beginning"

or a similar emotional heading.

The website should feel like a digital memory book that the couple can keep for years.

16. OPTIONAL FUTURE FEATURE

Keep the architecture ready for a possible future feature:

"Who Knows Them Better?"

This is NOT required in the first version.

Just make the website structure flexible enough that a fun quiz can be added later.

17. ANIMATION QUALITY

Animations are extremely important.

Use premium animations such as:

Smooth fade

Blur-to-clear image reveal

Cinematic image masking

Gentle zoom

Text appearing character-by-character where appropriate

Soft parallax

Elegant page transitions

Subtle floating particles

Light/shadow movement

Do NOT over-animate everything.

Animations should feel:
"Cinematic + Luxury + Emotional"

not:
"Gaming website + flashy effects."

18. PERFORMANCE

The website must remain fast.

Optimize images.

Avoid unnecessary libraries and heavy effects.

Animations should work smoothly on normal Android phones.

Make sure the initial suspense sequence does not take too long to load.

19. CONTENT EDITABILITY

Create the website so that I can easily replace:

Bride name

Groom name

Couple photos

Ganesh Ji image

Wedding date

Functions

Venues

Dress codes

Wedding card

Family information

Instagram link

Invitation message

Testimonials

Uploaded memories

Use clean reusable components and centralized data where practical.

20. FINAL DESIGN GOAL

The visitor's emotional journey should be:

"Wait... what is this?"

↓

"Something special is coming."

↓

"Who are these people?"

↓

"Ohhh... it's a wedding!"

↓

"I want to explore this."

↓

"This is actually beautiful."

The final result should feel like a premium digital wedding experience, not simply a webpage containing wedding information.

Build the first version as a polished, functional, mobile-first website with realistic placeholder content and images wherever actual information is not available.
